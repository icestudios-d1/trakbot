# Third-party code

`agent/cyril_agent/platform/xprop.py` and `windows_win32.py` are derived from
[ActivityWatch/aw-watcher-window](https://github.com/ActivityWatch/aw-watcher-window)
(MPL-2.0; license in `third_party/aw-watcher-window.LICENSE.txt`). Those files remain under MPL-2.0;
the rest of Cyril is original code. The agent's sampling approach (foreground window + AFK detection)
follows ActivityWatch's watcher design.
