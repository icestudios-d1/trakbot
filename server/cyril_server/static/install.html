Install agents

Put the Cyril agent on a Windows PC or a Mac with one pasted command. Removing it is one command too.

Install on

  1. Open PowerShell as administrator

    On the employee's PC: Start menu, type PowerShell, right-click, Run as administrator.

  2. Paste and run this

    Loading…
    It downloads the agent from this server, checks it, installs it to start whenever someone logs on, then waits for the PC's first report and tells you whether it arrived (and, if not, why). Safe to run again: it updates in place. To report under a name instead of the Windows login, add -User "Priya" after the closing bracket. The command contains the agent key, so share it only with whoever sets up PCs.

  3. Watch it appear

    The machine shows up in the list below within a minute or two, with a check for whether it can read web addresses and whether its screenshots are getting through.

Remove an agent

Same elevated PowerShell on that PC. Needs administrator rights on purpose, so staff cannot remove it themselves.
Loading…
Stops and deletes both scheduled tasks, the program, its config, key, log and spool files, and restores Incognito if an older installer had disabled it, then lists each item it removed. History already on the server stays until you delete it.

  1. Open Terminal on the Mac

    Applications, Utilities, Terminal (or press Cmd+Space and type Terminal). Use an account that is an administrator.

  2. Paste and run this

    Loading…
    It asks for the Mac's password (that is sudo), downloads the agent from this server, checks it, installs it to start whenever someone logs in, then waits for the Mac's first report and tells you whether it arrived. Safe to run again. To report under a name instead of the Mac login, change the end to sudo bash -s -- --user "Priya". The command contains the agent key, so share it only with whoever sets up Macs.

  3. Allow the two permissions, once

    macOS asks the person, and no installer can answer for them: Screen Recording (screenshots and window titles; System Settings, Privacy & Security, Screen Recording, switch cyril on, then it restarts itself) and, for each browser, Automation (click OK on "cyril wants to control Google Chrome"; this is how page addresses are read). The installer opens the Screen Recording pane for you. The machine list below shows when a permission is still missing.

  4. Watch it appear

    The Mac shows up in the list below within a minute or two.

Remove an agent

Same Terminal on that Mac. Needs sudo on purpose, so staff cannot remove it themselves.

Stops and deletes the agent job, the updater job, the program, its config, key, log and queued data, then lists each item it removed. History already on the server stays until you delete it. The permissions stay listed in System Settings but do nothing without the program.
